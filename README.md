RIVAL RUSH

A 2-Player Competitive 2D Game Built with Unity

Rival Rush is a 2D local multiplayer game where two players compete against each other on the same device. Use movement, jumping, and pushing mechanics to outplay your opponent and become the ultimate winner.

---

About the Game

Rival Rush is a Unity-based 2D game developed using C#. It offers an interactive two-player experience where both players compete using their own keyboard controls.

The game focuses on quick reactions, movement strategies, and well-timed pushes to eliminate the opponent.

Game Features

- Local Multiplayer: Two players can play together on the same computer.
- Player Movement: Smooth left and right movement.
- Jump Mechanics: Jump to avoid attacks and gain an advantage.
- Push Mechanism: Push your opponent away using dedicated controls.
- Knockback System: Realistic knockback effect when a player gets pushed.
- Respawn System: Players respawn after being eliminated.
- Character Animations: Running, jumping, and pushing animations.
- Competitive Gameplay: Challenge your opponent and try to win.

Controls

Action| Player 1| Player 2
Move Left| A| Left Arrow
Move Right| D| Right Arrow
Jump| W| Up Arrow
Push| F| Right Shift / Enter / Numpad 0

Technologies Used

- Game Engine: Unity
- Programming Language: C#
- Platform: Windows
- Version Control: Git and GitHub

How to Play

1. Launch the game.
2. Player 1 and Player 2 take their positions.
3. Use the keyboard controls to move and jump.
4. Use the push mechanism to knock your opponent away.
5. Avoid getting eliminated and compete to win.

Download and Installation

Play the Game

1. Open the repository on GitHub.
2. Navigate to the "Game" folder.
3. Download the complete game build.
4. Extract the downloaded files.
5. Run "Rival Rush.exe".

Note: Keep the ".exe" file, its corresponding "_Data" folder, and required DLL files together in the same directory.

Run the Unity Project

Clone the repository:

git clone https://github.com/Karannn2007/Rival_Rush.git

Then:

1. Open Unity Hub.
2. Select Add Project from Disk.
3. Choose the cloned "Rival_Rush" folder.
4. Open the project using a compatible Unity Editor version.
